# Referencias reales incluidas

- `SALIDA_DGS.xlsx`: archivo DGS real suministrado por el usuario. Se usa para estudiar y verificar la
  estructura de hojas/columnas DGS. Algunas hojas del archivo están vacías; no debe suponerse un campo
  que el archivo no demuestra.
- `M_ALIMENTAD.xlsx`: tabla real de una exportación de datos de red. Se usa como referencia de schema
  discovery/mapping, no como fuente universal ni como mapping hardcodeado.

Nunca sobrescribir estos archivos durante una conversión. Copiar a `output/` si se necesita experimentar.
